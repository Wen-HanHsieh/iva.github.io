IVA: Instruct-Verify-and-Act

Teaching Vision-Language-Action Models to Reject the Impossible

Wen-Han Hsieh*, Elvis Hsieh*, Dantong Niu, Trevor Darrell, Roei Herzig, David M. Chan
University of California, Berkeley * equal contribution
arXiv PDF Code & Data

Abstract

IVA is a unified framework for Vision-Language-Action models that detects when an instruction is unfulfillable (false premise), clarifies or corrects it in natural language, and then acts safely. Trained with paired true- and false-premise instructions, IVA improves false-premise handling while maintaining strong true-premise task performance.

Method

  • End-to-end instruction tuning on a unified dataset; unlike LLaRVA’s two-stage pipeline, IVA trains in one stage for action prediction, FP detection, and language correction. :contentReference[oaicite:0]{index=0}
  • Model I/O: input is the front camera plus the previous 5 joint positions; output predicts a 2D visual trace and the next-step action as an 8D vector (7 joint velocities + binary gripper). :contentReference[oaicite:1]{index=1}
  • Frozen encoders + LoRA decoder: vision & language encoders are frozen; the auto-regressive transformer decoder is fine-tuned with LoRA.
  • Training mix: ~800 episodes per task; ~65% In-Domain FP injected at 10% of steps and ~20% Out-of-Domain FP; remaining are true-premise.

Evaluation Procedure

  • (1) Detection: classify the response as Accept (TP) or Clarify/Refuse (FP); score per step, then average.
  • (2) Execution: if Accept, execute predicted 8D action sequence; RLBench success detector judges success/failure.
  • (3) Overall: average Detection + Execution across 225 episodes (25 × 9 tasks).

Setup: 9 RLBench tasks, 25 episodes each, randomized object poses; each episode paired with a true or false-premise prompt.

Results

  • In-Domain FP detection: 100% (perfect) across tasks.
  • Gains vs baseline: FP detection accuracy improves by +97.56%; successful responses in FP scenarios increase by +50.78%.
